# SGR³ Model: Scene Graph Retrieval-Reasoning Model in 3D

Research code for retrieval-augmented 3D scene graph prediction from RGB sequences.

## Repository Structure

- **[`3DSSG/`](3DSSG/)** — 3D scene graph framework, data preprocessing, feature extraction, and knowledge-base indexing.
- **[`RAG_baseline_Qwen3/`](RAG_baseline_Qwen3/)** — Qwen3-VL baseline implementations and alternative RAG approaches.
- **[`RAG_agentic/`](RAG_agentic/)** — Main SGR³ pipeline, frame filtering, retrieval, graph prediction, and ablation experiments.
- **[`RAG_Rexplore_Qwen3/`](RAG_Rexplore_Qwen3/)** — Exploratory experience abstraction and window-level retrieval methods.
